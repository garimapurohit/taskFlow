# 🚀 InternFlow

> **Track your coding journey, manage job applications, and stay interview-ready — all in one place.**

InternFlow is a full-stack productivity platform designed for students and aspiring software engineers to organize their placement preparation. It helps users manage DSA progress, track internship/job applications, maintain interview notes, and monitor daily learning goals through a clean and responsive dashboard.

---

## ✨ Features

### 👤 Authentication

* Secure user registration and login
* JWT-based authentication
* Password hashing using bcrypt
* Protected routes

### 📊 Personalized Dashboard

* Welcome dashboard with productivity overview
* Daily learning streak
* Progress statistics
* Recent activities

### 💻 DSA Tracker

* Add solved problems
* Track platform and difficulty
* Filter by topic or status
* Monitor coding progress

### 💼 Job Application Tracker

* Save company applications
* Track application status
* Store interview dates
* Add recruiter notes

### 📝 Interview Notes

* Create and manage interview experiences
* Store HR and technical questions
* Organize preparation notes

### 🎯 Daily Goals

* Set learning goals
* Mark goals as completed
* Track consistency and productivity

### 🔍 Search & Filter

* Search applications, notes, and problems
* Filter by category or status

### 📱 Responsive Design

* Mobile-friendly interface
* Clean and modern UI
* Smooth user experience
